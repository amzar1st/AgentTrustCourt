# Frontend

The production-ready demo is the static bundle in `../dist/`. It uses the official GenLayerJS browser bundle from ESM CDN, so the Site can be hosted without a Node build step.

The console defaults to the verified Studionet contract at `0x65967F7Cc6b3BE9a1D49B0852ec1d5a29c8Bd155`. Connect MetaMask to submit writes, or enter another deployed address and choose its matching network. The app never asks for or stores a private key.
